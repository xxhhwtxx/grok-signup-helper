# Grok 注册助手 v0.1.0

安装后打开桌面“Grok 注册助手”。首次使用请自行导入邮箱并设置密码。

1. 阅读官网条款，勾选同意；选“注册当前邮箱”或“连续注册”。
2. 自动填写邮箱、姓名和注册密码，读取本次新验证邮件并填写验证码。
3. 人机验证、真实年龄/生日及手机验证由本人完成。完成后助手继续。
4. 成功必须由官网显示匹配的登录邮箱确认。连续注册仅在成功且记录保存后处理下一邮箱。若身份在菜单内，请打开官网账号菜单。
5. 每个邮箱的浏览器资料独立保存；可用“打开此账号的 Grok”访问，或“自动登录”。关闭助手不会清除浏览器资料。
6. 支持 mokeyun 的四横线格式及 icsms 的三横线密钥格式，密钥不会被当作注册密码。
7. 复制账号资料/导出备份包含密码，请自己保管。这里导出的是账号资料，不是 API Key 或其他软件的登录 Token。官网未要求设置密码时，配置密码不代表官网已设置。

网站可能限制地区、网络、注册频率或 WebView2；助手会停在官网提示处，不绕过验证和访问限制。若遇到新的未知字段，按页面填写后继续。

自行配置的便携包可能含个人邮箱取信密钥和注册密码，请自行保管。源码包不包含这些数据。账号库保存在 LocalAppData\local.grok.signuphelper，独立于其他助手。
